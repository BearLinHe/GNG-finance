# 财务助手

运行 `npm run dev:assistant -- -p 3001`，打开
<http://127.0.0.1:3001/>，从任意页面左下角打开「财务助手」。桌面可以边查账边浏览；手机以全屏对话显示。收起窗口、切换模块不会清空当前会话。
普通开发服务和 Vercel Preview 默认不启用。不要把本地服务用隧道或反向代理公开。

生产站通过 HTTPS 访问，所有能打开网站的访客都能直接使用助手，无需登录或单独的访问码。访客可以查询真实财务数据，并可在预览后确认自己的账务修改；确认不是管理员审批。如果不希望公开账本，请限制整个网站的访问。AI 请求使用项目的 API 额度。

在 Vercel 的 **Production** 环境配置服务端 Secret `OPENAI_API_KEY`，不要加 `NEXT_PUBLIC_` 前缀；修改环境变量后重新部署。旧变量 `FINANCE_ASSISTANT_ACCESS_CODE` 已不再使用，可删除。浏览器会自动取得匿名会话，用于隔离不同访客的草稿，不用向助手发送任何密钥。

待确认草稿保存在系统库，绑定当前会话，15 分钟后不可使用；跨实例确认和重复点击不会重复记账。仅预览不改动账务明细。

- **单柜核算**：OAK、SAV 页面可只读分析当前页面的摘要。分页合计只代表当前页。各页面的助手也支持核对 OAK 司机工单；不会因此更改单柜账单。
- **按司机核对工单**：直接在左下角输入，例如「查刘嘉耀 2026 年 9 月 15 日的还柜和回程，列出待核对项」。可以指定每段收入、按已有标准计价，或并到同批次的主作业。多段相似时，用柜号或回复中的 `#工单编号` 指定；影响的收入和归属会列在同一份预览里。只有点击「确认整批核对」才写入。预览 15 分钟内有效；工单变化或结算锁定时整批不保存。
- **不使用 AI 密钥**：在运输部打开助手并点击「David 周期试算」，从现有主表口径读取真实结果，不写账。
- **分析 / 总结**：在未纳入版本控制的 `.env.local` 配置新的服务端 `OPENAI_API_KEY`，重启上述服务。可用 `OPENAI_MODEL` 指定支持工具调用的模型。聊天、发送的 Excel 可见内容，以及回答问题需要的核算数据会发给 OpenAI；检查附件后再发送。
- **拟改账**：可以新增油费、保险和其他费用，或按原单号修改金额。先核对车号、账期和修改前后金额，再点击「确认入账」。草稿 15 分钟有效，最多 40 行。若出现重复费用、无对应车号或原单已变化，整批不会保存。
- **数据口径**：司机盈亏沿用主表，区分已确认与待核对。期间账本汇总仅统计账期完整落入所选范围的系统明细，不代表按天分摊后的盈亏；外部维修库和自动作业收入不计为手工账本收入。

助手不执行任意数据库语句，也不会修改工资源表、外部维修单或计价规则。测试时只生成草稿不会改变真实账本；确认后才会生效并记录修改前后值。
